## Projeto em destaque

### NekkoData

Plataforma voltada à **centralização, análise e gestão de dados operacionais**, com recursos de automação, indicadores e integração entre sistemas.

Principais pontos do projeto:

- ETL utilizando **Python e pandas**.
- Integração de dados entre **MySQL e PostgreSQL**.
- Tratamento, validação e controle de qualidade dos dados.
- Construção de indicadores operacionais e gerenciais.
- Desenvolvimento de APIs com **FastAPI**.
- Frontend com **React e TypeScript**.
- Dashboards e visualizações para apoio à tomada de decisão.
- Integração com APIs e sistemas externos.
